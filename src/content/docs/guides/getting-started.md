title: Getting started
description: Create, develop, and deploy an electronics documentation site using pnpm.
---

## Create a site

Use **Use this template** on GitHub, then clone your new repository. Install **Node.js 24 or later** and **pnpm 11.24.0** (the version pinned in `package.json`).

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Astro. This repository defaults to `/electronic-docs-template/` so local development also exercises GitHub Pages project paths.

## Write a page

Add a `.md` or `.mdx` file under `src/content/docs/`, with a title in its frontmatter:

```md
---
title: My circuit notes
description: Notes on a new circuit.
---

## Design

Describe your circuit here.
```

Use `.mdx` when importing `Circuit.astro` or `WaveDrom.astro`. Add the new page to `sidebar` in `astro.config.mjs`, or use Starlight's autogenerated sidebar.

## Validate and preview

```sh
pnpm exec playwright install chromium
pnpm validate
pnpm preview
```

Validation checks Astro and TypeScript, component behavior, the production build, and browser tests. CI installs Chromium with its Linux dependencies.

## Deploy to GitHub Pages

In your repository's **Settings → Pages**, choose **GitHub Actions** as the source. Pushing to `main` runs validation and publishes `dist/`. Pull requests build and test without publishing.

The workflow obtains `SITE_URL` and `BASE_PATH` from GitHub Pages configuration. This supports project sites, user sites, and custom domains. Set those environment variables explicitly when building for another host. `GITHUB_REPOSITORY=owner/name` also customizes repository and edit links for a fork.

```sh
# A custom domain served at its root:
SITE_URL=https://docs.example.com BASE_PATH=/ pnpm build
```

Serve the output over HTTP; opening generated HTML with `file://` prevents simulator and search resources from loading correctly.
